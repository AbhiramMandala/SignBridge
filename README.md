# SignBridge — ASL Alphabet MVP (static letters)

One-line pitch: point your webcam at a static ASL alphabet sign, get the letter back with confidence.

**Honest scope:** static ASL alphabet letters (A–Z plus `space`/`del`/`nothing` where the dataset has them) from a single image via MediaPipe hand landmarks + a small scikit-learn classifier. This is **not** a full sign-language translator — no motion, no words/sentences, no video.

## How it works
```
Image (webcam/upload) → MediaPipe Tasks HandLandmarker (21 xyz joints)
  → left hands mirrored to right-hand orientation
  → translate to wrist origin + scale-normalize → 63-dim vector
  → scikit-learn classifier → letter + confidence (+ top-3)
```
Single hand only: if several are visible, the first/most-confident detection is used. Below the confidence threshold the app shows **uncertain** instead of guessing.

## Results (measured 2026-10-09, from `models/metrics.json` — not estimated)

Data: 87,000 files on disk (29 labels × 3,000). Cap 1,000/class → 29,000
candidates; **kept 25,171, skipped 3,829 (13.2%)** — skips are unreadable (0
found in spot checks) or no-hand frames. `nothing` was skipped 1,000/1,000
(hand-free images yield no landmarks) and excluded from training; at runtime
that case is covered by the no-hand path. Highest-skip letters: M (477), N
(433), space (345). Extraction took 1,381 s on CPU.

Split (stratified, seeded, before augmentation): 28 classes; train 17,619 real
+ 17,619 jittered copies = 35,238; val 3,776; test 3,776. Training took 152 s.

| Model | Val acc | Test acc |
|---|---|---|
| LogisticRegression | 0.9772 | – |
| RandomForest (200 trees) | 0.9889 | – |
| MLP (128) ← selected on val | 0.9907 | **0.9934** |

Test macro precision/recall/F1: 0.9931 / 0.9925 / 0.9927. Weakest F1: M
0.974, U 0.976, N 0.977, R 0.979, space 0.985. Confusion matrix:
`docs/confusion_matrix.png` (generated by `src/train.py`).

Separate Kaggle-test-image check (`data/kaggle_test/`, 28 images, `del`
absent from the archive): 14 processed → **14/14 correct**; 14 returned
no-hand (incl. `nothing_test.jpg`, correctly hand-free). Same uniform
backgrounds as training — do NOT read this as real-world accuracy.

- Custom webcam sanity check (`data/custom_test/`): not provided yet —
  run `python scripts/custom_check.py` once you add photos.
- Known weakness: the Kaggle ASL Alphabet set has near-duplicate frames and uniform backgrounds, so dataset test accuracy overstates real-world accuracy. J and Z need motion and are **not** meaningfully recognizable from a static frame — treated as static classes only (see Limitations).

## Setup (5 steps, Windows PowerShell)
1. `py -m venv .venv` → `.\.venv\Scripts\Activate` (verified on Python **3.14.7** with `mediapipe==1.1.0`, which uses the Tasks HandLandmarker API)
2. `pip install -r requirements.txt`
3. Get data: `pip install kaggle`, place `kaggle.json` (see `data/README.md`), then `python scripts/download_data.py`
4. `python -m src.dataset` (extracts landmarks, caches `.npz`)
5. `python -m src.train` then `python app.py` → open the local URL.

## Dataset
- Name: **ASL Alphabet** by grassknoted (Akash). URL: https://www.kaggle.com/datasets/grassknoted/asl-alphabet
- ~87k 200×200 images, 29 classes (26 letters + SPACE/DELETE/NOTHING), ~1.1 GB.
  License: **GPL 2** (Kaggle API metadata `licenseName: "GPL 2"`, verified
  2026-10-09; dataset version 1). Do not redistribute the archive; keep it out
  of git. Bundle includes a 29-image test set — use real-world photos instead.
- Citation: Akash Nagaraj (2018), "ASL Alphabet", Kaggle,
  https://www.kaggle.com/datasets/grassknoted/asl-alphabet,
  DOI 10.34740/KAGGLE/DSV/29550.

## Train / evaluate / run
- `python scripts/download_data.py [--limit N]` — download (needs YOUR Kaggle creds, never committed)
- `python -m src.dataset [--limit N]` — landmarks → `data/processed/landmarks.npz` + `skipped.json`
- `python -m src.train` — compare 3 classifiers, save best to `models/`, test evaluated once
- `python scripts/custom_check.py` — optional webcam-photo sanity check on
  `data/custom_test/<LETTER>/*.jpg` (reported separately, never mixed into test metrics)
- `python -m pytest tests/ -q` — test suite (run from `signbridge/`)
- `python app.py` — Gradio UI (webcam snapshot + upload, word builder)
- First run auto-downloads `hand_landmarker.task` (~9 MB) into `models/` (gitignored).

## Deploy to Hugging Face Spaces
1. Create a Space: SDK **Gradio**, hardware **CPU (free)**.
2. Upload the contents of `signbridge/` as Space root (`app.py` at root, `src/`, `requirements.txt`, `models/model.joblib` + `labels.json` if <5 MB).
3. Copy `HF_README.md` content to the Space README (sets `sdk: gradio`, `app_file: app.py`).
   First prediction auto-downloads `hand_landmarker.task` (~9 MB); to skip that,
   upload it into the Space's `models/` yourself.
4. Space builds and launches `python app.py` automatically. No secrets needed.

## Limitations
- Static letters only; **J and Z require motion** — included as static classes at best, unreliable by design.
- Sensitive to lighting, cluttered backgrounds, skin-tone/hand-shape bias in the dataset.
- Detector misses dark/backlit hands: on the 28 Kaggle test images, 14 returned
  no-hand at the fixed operating point (`min_hand_detection_confidence=0.5`).
  A diagnostic sweep showed 0.3 recovers 4 more with no blank-image false
  positives, but the shipped threshold is unchanged — retuning would invalidate
  the trained cache and reported metrics, so it stays a documented limitation.
- MLP = one 128-unit hidden layer (`max_iter=500`); confidence is uncalibrated.
- Single hand, frontal-ish view; needs full hand in frame.
- Dataset test accuracy is inflated (near-duplicates, uniform backgrounds) — trust the webcam sanity check more.
- CPU-only, English ASL alphabet only.
